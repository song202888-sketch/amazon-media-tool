# Amazon 素材助手详细使用说明

## 一、安装前准备

需要 Google Chrome 或兼容的 Chromium 浏览器、一个固定的扩展文件夹、足够的磁盘空间；下载较大视频时还需要足够的浏览器内存。

不要直接双击 ZIP 使用，也不要解压到会被自动清理的临时目录。Chrome 加载的是解压文件夹，移动或删除该文件夹后扩展会失效。

## 二、详细安装步骤

1. 下载 `amazon-media-tool-v1.0.2-unpacked.zip`；
2. 完整解压 ZIP；
3. 确认解压目录根部存在 `manifest.json`；
4. 在 Chrome 打开 `chrome://extensions`；
5. 开启右上角“开发者模式”；
6. 点击“加载已解压的扩展程序”；
7. 选择包含 `manifest.json` 的文件夹；
8. 确认名称是“Amazon 素材助手”，版本是 `1.0.2`；
9. 把扩展固定到 Chrome 工具栏；
10. 刷新所有已经打开的 Amazon 页面。

## 三、更新扩展

推荐使用新文件夹安装新版本：

1. 下载和解压新版；
2. 在 `chrome://extensions` 删除旧版；
3. 加载新版文件夹；
4. 刷新 Amazon 页面；
5. 确认新版正常后再移除旧文件夹。

如果直接覆盖原文件夹，需要在扩展管理页点击“重新加载”，然后刷新 Amazon 页面。

## 四、下载整套商品图

1. 打开目标商品详情页；
2. 确认页面显示正确的 ASIN；
3. 先选择目标颜色、尺寸或款式；
4. 等待主图和缩略图出现；
5. 打开“Amazon 素材助手”；
6. 检查 ASIN、标题和图片数量；
7. 全选或取消不需要的图片；
8. 点击“整套打包 ZIP”；
9. 保持弹窗打开直到完成；
10. 到 Chrome 下载目录查找 ZIP。

扩展会优先把带尺寸裁剪参数的 Amazon 图片地址恢复为原图地址；原图不可用时会回退到页面原始地址。

## 五、下载不同变体的图片

1. 下载当前变体的 ZIP；
2. 关闭扩展弹窗；
3. 在商品页切换到另一个变体；
4. 等待图片更新；
5. 重新打开扩展并点击刷新；
6. 再次打包下载。

建议每个变体分别保存，不要把不同变体图片混到同一个 ZIP。

## 六、下载普通商品视频

1. 安装或更新扩展后刷新商品页；
2. 找到目标视频并播放几秒；
3. 打开扩展；
4. 点击“刷新视频列表”；
5. 点击目标项目的“下载 MP4”；
6. 保持弹窗打开；
7. 等待分片下载和本地转换；
8. 到 Chrome 下载目录检查 MP4。

较大视频可能同时占用下载数据、转换数据和最终 MP4 所需内存，因此实际内存占用可能明显大于文件本身。

## 七、清除视频记录

- 点击视频区域右上角清除按钮，可以清空当前标签页记录；
- 关闭商品页标签后，Chrome 会清除该标签页的会话记录；
- 扩展不会把视频地址上传到服务器。

## 八、下载文件在哪里

默认保存在 Chrome 当前下载目录。打开 `chrome://settings/downloads` 可以查看或修改下载位置。如果启用了“下载前询问保存位置”，生成 ZIP 或 MP4 时会出现保存提示。

## 九、故障排查顺序

1. 当前是否为 Amazon 商品详情页；
2. 安装或更新后是否刷新页面；
3. 商品素材是否实际加载；
4. 是否选择正确变体；
5. Chrome 是否拦截下载；
6. 网络是否稳定；
7. 磁盘空间和内存是否足够；
8. 视频是否为未加密 MPEG-TS HLS；
9. 临时视频地址是否过期；
10. Amazon 是否改变页面结构。

提交 GitHub Issue 时，可提供国家站点、公开商品链接、扩展版本、实际现象、预期结果和不含敏感信息的截图。不要公开密码、Cookie、付款信息、订单或带访问令牌的视频地址。
