# Amazon 素材助手

一款独立开发的 Chrome Manifest V3 扩展，用于整理 Amazon 商品图片和普通商品视频。

## 能做什么

- 自动识别当前商品详情页的主图和图集；
- 去除 Amazon 缩略图尺寸参数，优先获取原始高清图；
- 支持预览、全选、取消全选和单独勾选；
- 把选中的整套商品图打包成一个 ZIP；
- 按 ASIN 与商品标题建立文件夹并顺序编号；
- 捕获当前商品页播放的普通 HLS 商品视频；
- 在多清晰度播放列表中优先选择最高分辨率或最高码率；
- 在浏览器本地把未加密的 MPEG-TS HLS 转封装成 MP4；
- 不含广告、分析埋点、账号读取或数据上传接口。

## 下载哪个文件

普通使用者只需要下载 Release 中的：

```text
Amazon素材助手-v1.0.2-可加载版.zip
```

需要查看或修改代码的开发者，可以克隆仓库后自行构建。

## 第一次安装

1. 下载 `Amazon素材助手-v1.0.2-可加载版.zip`。
2. 把 ZIP 完整解压到一个固定文件夹，不要直接从压缩包内部加载。
3. 在 Chrome 地址栏输入并打开 `chrome://extensions`。
4. 打开页面右上角的“开发者模式”。
5. 点击“加载已解压的扩展程序”。
6. 选择刚才解压的文件夹。正确的根目录中应有：

   ```text
   manifest.json
   popup.html
   popup.js
   background.js
   content.js
   icons/
   ```

7. 确认扩展列表中出现“Amazon 素材助手”。
8. 点击 Chrome 工具栏的扩展图标，把“Amazon 素材助手”固定到工具栏。
9. 刷新已经打开的 Amazon 商品页。安装前已打开的页面不会自动加载新扩展。

更完整的安装、更新和故障处理步骤见[详细使用说明](docs/详细使用说明.md)。

## 一键下载整套商品图

1. 打开一个 Amazon 商品详情页。
2. 如果商品有颜色、尺寸或款式变体，先切换到要下载的具体变体。
3. 等待主图和缩略图加载完成。
4. 点击工具栏中的“Amazon 素材助手”。
5. 检查扩展识别出的图片数量和预览。
6. 默认选择全部图片，也可以取消不需要的图片。
7. 点击“整套打包 ZIP”。
8. 在进度完成前保持扩展弹窗打开，不要切换到其他页面。
9. ZIP 会保存到 Chrome 当前设置的下载目录。

ZIP 内部通常类似：

```text
B0XXXXXXXX_商品标题/
├── 01.jpg
├── 02.jpg
├── 03.jpg
└── 下载说明.txt
```

`下载说明.txt` 会记录商品标题、ASIN、来源页面、导出时间、成功数量和失败明细。

“整套商品图”指当前页面所选变体的图集。不同颜色或款式需要分别切换后再次下载。

## 下载普通商品视频

1. 安装或重新加载扩展后，刷新 Amazon 商品详情页。
2. 找到页面中的目标商品视频并至少播放一次。
3. 等待视频开始播放几秒，让页面发出 HLS 媒体请求。
4. 打开“Amazon 素材助手”。
5. 如果列表还没有出现视频，点击“刷新视频列表”。
6. 点击对应项目的“下载 MP4”。
7. 在分片下载和转换完成前保持扩展弹窗打开。
8. 转换完成后，MP4 会保存到 Chrome 下载目录。

当前视频功能只支持未加密的 MPEG-TS HLS，不支持：

- Prime Video DRM 内容；
- 加密 HLS；
- fMP4 分片；
- 音视频分轨；
- 字幕合并；
- 需要绕过账号、订阅或访问限制的视频。

较大的视频会占用较多浏览器内存。转换期间请避免关闭弹窗、刷新页面或让电脑进入睡眠。

## 常见问题

### 扩展里没有商品图

- 确认当前是 Amazon 商品详情页，不是搜索结果、店铺首页或订单页面；
- 安装扩展后刷新商品页；
- 等待页面主图和缩略图加载完成；
- 切换一次商品变体后再点击扩展中的刷新按钮；
- 某些新版或实验版 Amazon 页面结构可能需要后续适配。

### 只识别出一张图片

- 先点击或滑过页面左侧或下方的其他缩略图；
- 等待懒加载图片完成；
- 点击扩展中的刷新按钮；
- 检查当前变体是否本来就只有一张图片。

### 商品图 ZIP 没有下载

- 保持扩展弹窗打开直到进度完成；
- 检查 Chrome 下载设置或下载拦截提示；
- 检查磁盘空间；
- 重新打开扩展后减少一次打包的图片数量。

### 没有捕获到视频

- 安装扩展后先刷新商品页；
- 必须实际播放目标视频，而不只是看到视频缩略图；
- 播放几秒后再打开扩展；
- 当前页面的视频可能不是本扩展支持的 HLS 命名格式；
- 页面可能使用加密、DRM 或其他媒体格式。

### 视频转换失败

- 视频地址的临时签名可能已经过期，请刷新页面并重新播放；
- 网络中断可能造成分片下载失败；
- fMP4、DRM 或加密 HLS 不支持；
- 视频过大时可能因浏览器内存不足而失败。

## 权限和隐私

- `downloads`：保存用户主动生成的商品图 ZIP 和视频 MP4；
- `storage`：把捕获的视频地址暂存在 Chrome 会话存储中，关闭标签页后清除；
- Amazon 站点与 Amazon 媒体域名权限：识别当前商品页素材并获取用户主动下载的媒体文件。

扩展没有以下权限或行为：

- 没有 `<all_urls>`；
- 没有 `webRequest`；
- 不读取 Cookie、浏览历史、账号密码或付款信息；
- 不运行远程代码；
- 不连接广告、分析或开发者后端接口；
- 不上传商品标题、ASIN、图片地址或视频地址。

完整说明见[隐私说明](PRIVACY.md)和[安全策略](SECURITY.md)。

## 从源代码构建

需要 Node.js 22 或兼容版本：

```bash
npm ci
npm run build
npm run check
```

成功后，可加载的扩展位于 `dist/`。进入 `chrome://extensions`，开启开发者模式，点击“加载已解压的扩展程序”，然后选择 `dist` 文件夹。

详细开发、测试和 GitHub 发布步骤见[源码构建与 GitHub 发布说明](docs/源码构建与GitHub发布.md)。
